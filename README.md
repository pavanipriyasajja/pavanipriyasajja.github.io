## ✏️ How to Edit Content

### Edit text on any page
Open the relevant `.html` file and find the text you want to change. Each page is clearly labelled.

### Change a project title or description
Open `projects.html` for the card text, or `project-1.html` through `project-4.html` for full case study content.

### Swap an image
Replace the file in the `images/` folder with your new image — keep the same filename.

### Change colors or fonts
Open `style.css` and update the `:root` CSS variables at the top.

### Add a new project
1. Duplicate `project-1.html` and rename it (e.g. `project-5.html`)
2. Update the content inside
3. Add a new card in `projects.html` linking to the new file

## 🚀 Publish on GitHub Pages

1. Create a new GitHub repo (e.g. `portfolio`)
2. Upload all files (keeping the folder structure)
3. Go to **Settings → Pages → Source → Deploy from branch → main / root**
4. Click Save — live at `https://your-username.github.io/portfolio/`
